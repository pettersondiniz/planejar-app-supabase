# Planejar App Supabase

Skill para conduzir a descoberta e o planejamento de pequenos aplicativos web com React, Vite, shadcn/ui, Supabase e Cloudflare Pages.

## Conteúdo

- `SKILL.md`: instruções principais da skill.
- `references/`: materiais de apoio para entrevista, ambientes e autenticação.
- `scripts/Test-AppEnvironment.ps1`: verificação segura de pré-requisitos locais.

## Uso

No Codex, invoque a skill com `$planejar-app-supabase` ou descreva que deseja planejar um aplicativo com Supabase.
